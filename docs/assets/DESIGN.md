# Evidence Architecture

Use a restrained dark canvas with a regular grid, precise alignment and generous margins. Depth comes from offset planes that preserve reading order. Every visible layer has a distinct informational role.

Cyan identifies reproducible operations, green identifies verified execution environments, and amber identifies the semantic boundary. Color reinforces labels rather than replacing them. Contrast and spacing take priority over ornament.

Large figures introduce a small set of measured outcomes. Compact monospaced labels connect those figures to the underlying experiments. Careful typographic hierarchy makes the visual readable at README width and at full resolution.

The counterexample occupies a separate plane so the reader can distinguish passing behavioral assertions from valid application output. The image is a dated evidence snapshot, not a live dashboard or a claim of exhaustive coverage. Precision in wording is part of the visual design.

The headline explicitly limits verification to eight regeneration scenarios. Enlarged card labels and captions support reading the overview at typical README widths; the linked evidence remains the text-based reference for the measurements.
